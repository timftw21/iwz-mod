IWZ-MOD CUSTOM LOBBY MUSIC
==========================

Drop audio files into this folder, then open:

  Zombies > Headquarters > Lobby Music > Custom Music

Supported formats:

  MP3, WAV, FLAC, OGG Vorbis, OGG Opus (including .oga files)

The list is refreshed whenever the Custom Music menu opens. If you add or
remove files while the menu is already open, use the REFRESH button shown in
the menu's button helper bar.

Selecting a track previews it immediately and saves it as the active Zombies
lobby track. Selecting any built-in lobby song disables the custom selection.
